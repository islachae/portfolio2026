# Mellon 설치 안내 (초대받은 친구용)

Mellon은 Gmail 옆에 붙는 크롬 패널이에요. 최근 메일을 읽고 **"지금 뭘 먼저 해야 하는지"** 순서대로 정리해 줘요. 마감, 요약, 캘린더 넣기, 메일에 대해 묻기 같은 기능이 있어요.

시작하기 전에 초대한 사람에게 **세 가지**를 받아 두세요.
1. **스토어 링크**
2. **Google client ID** (`....apps.googleusercontent.com`으로 끝나는 긴 글자)
3. **Claude API 키** (`sk-ant-...`로 시작하는 글자)

그리고 초대한 사람에게 **Mellon에 쓸 Gmail 주소**를 알려줘야 해요. 그 주소가 등록돼 있어야 로그인할 수 있어요.

---

## 1. 설치 (1분)
1. 받은 **스토어 링크**를 크롬에서 여세요 → **Chrome에 추가** → **확장 프로그램 추가**를 누르세요.
2. 툴바의 퍼즐 조각 🧩 아이콘을 누르고 → **Mellon** 옆의 핀을 눌러 고정하세요.

## 2. 처음 실행 (3분)
1. **Gmail**을 열고 → 툴바의 **Mellon 얼굴 아이콘**을 누르세요. 오른쪽에 패널이 열려요.
2. 언어(English / 한국어)와 관심 분야를 고르고 → **계속**을 누르세요.
3. 패널 위쪽의 **⚙ 설정**을 누르고 아래 두 칸을 채운 뒤 → **저장**을 누르세요.
   - **Google OAuth client ID** 칸 ← 받은 client ID
   - **Claude API 키** 칸 ← 받은 API 키
4. 패널로 돌아와 **Google로 로그인**을 누르고 → 초대한 사람에게 알려준 Gmail 계정을 고르세요.
5. **"Google에서 확인하지 않은 앱"** 화면이 나와요. 테스트 중인 앱이라 정상이에요.
   - 화면에 **계속** 버튼이 보이면 누르세요.
   - 안 보이면 **고급 → Mellon(으)로 이동**을 누르세요.
6. **Gmail 읽기** 권한을 허용하세요. Mellon은 메일을 **읽기만** 해요.

처음에는 최근 메일을 읽느라 30초~1분쯤 걸려요. 다음부터는 금방 열려요.

## 3. 써보기
- **해야 할 일**에는 마감이 빠른 순서로 정리돼요. 카드에 마우스를 올리면 **✓ 완료**가 나와요.
- 카드를 누르면 요약, 핵심 정보, 원문을 볼 수 있어요. **캘린더에 넣기**도 여기 있어요.
- 아래 입력창에서 **Mellon에게 물어볼 수 있어요.** 예: "이번 주 마감 알려줘", "답장 초안 써줘"
- **⚠ 먼저 확인**으로 분류된 메일은 피싱일 수 있으니 링크를 누르지 마세요.

## 개인정보, 이건 알아두세요
- Mellon에는 **서버가 없어요.** 메일은 내 크롬에서 Claude(Anthropic)로만 보내져서 요약되고, 결과는 **내 컴퓨터에만** 저장돼요.
- **초대한 사람도 내 메일을 볼 수 없어요.** 받은 API 키로 쓰면 사용량(비용)만 그 사람 계정에 청구돼요.
- **받은 API 키는 다른 사람에게 주지 마세요.** 비용이 초대한 사람에게 나가요.
- 그만 쓰고 싶으면 크롬에서 Mellon을 **삭제**하면 저장된 내용도 모두 지워져요.
- 자세한 내용은 [개인정보 처리방침](https://chaewon.works/mellon/privacy/)에 있어요.

## 잘 안 될 때
| 화면에 나온 말 | 해결 |
|---|---|
| "access_denied" / "액세스 차단됨" | 초대한 사람이 내 Gmail을 아직 등록하지 않았어요. 주소를 다시 알려주세요. |
| 학교 계정이 "관리자가 차단함" | 학교 설정 때문이에요. 개인 Gmail로 써보세요. |
| "Claude API key is not valid" | 설정에서 키를 다시 붙여 넣으세요. 앞뒤에 공백이 없는지 확인하세요. |
| 로그인하라고 다시 나와요 | 크롬을 껐다 켜면 로그인이 풀려요. **Google로 로그인**을 다시 누르세요. |

궁금한 점이나 고쳤으면 하는 점은 초대한 사람에게 편하게 알려주세요. 🍈
